# Frontend Mentor - Recipe Page

Esta é a minha solução para o desafio **Recipe Page** do Frontend Mentor.

## 🚀 O Projeto

O objetivo deste desafio foi construir uma página de receita focada na construção de páginas semânticas com a utilização das tags do HTML5 e em boas práticas de arquitetura CSS, garantindo que o conteúdo seja estruturado de forma lógica e legível.

## 🧠 O que eu aprendi
Durante a construção deste projeto, aperfeiçoei a utilização de listas ordenadas (`<ol>`) e não ordenadas (`<ul>`) para representar dados estruturados de forma semântica. Também pratiquei o controle de espaçamento e tipografia para garantir que textos longos (como instruções de preparo) mantenham uma boa hierarquia visual e legibilidade em diferentes tamanhos de tela.
