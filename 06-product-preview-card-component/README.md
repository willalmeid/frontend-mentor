# Frontend Mentor - Product Preview Card Component

Esta é a minha solução para o desafio **Product Preview Card Component** do Frontend Mentor.

## 🚀 O Projeto

O objetivo deste desafio foi construir um card de visualização de produto focado na construção de páginas semânticas com a utilização das tags do HTML5 e em boas práticas de arquitetura CSS, trabalhando especialmente a responsividade e o gerenciamento de diferentes ativos de imagem.

## 🧠 O que eu aprendi
Neste projeto, aprofundei meus conhecimentos em design responsivo ao gerenciar a troca de imagens entre mobile e desktop. Pratiquei a utilização de fontes personalizadas com o Google Fonts e o ajuste fino de espaçamentos para garantir que a hierarquia visual do produto (preço, categoria e descrição) fosse mantida em todas as resoluções.

- CSS3
